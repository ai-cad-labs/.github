# Getting help with AI-CAD

## Where to ask

| Channel | Best for |
|---|---|
| [Issues](https://github.com/ai-cad-labs/ai-cad/issues) | Bugs and defects |
| [Discussions](https://github.com/ai-cad-labs/ai-cad/discussions) | Show your runs, ask questions, propose machines |

## Self-serve first

- **"What should healthy output look like?"**:
  study a complete run in the
  [run gallery](https://github.com/ai-cad-labs/ai-cad-example-projects)
  before changing pipeline behavior.
- **Conventions and internals**:
  [`AGENTS.md`](https://github.com/ai-cad-labs/ai-cad/blob/main/AGENTS.md)
  is the canonical map for anyone (human or agent) working in the flagship repo.
- **CadQuery itself**: the flagship's
  [`reference/`](https://github.com/ai-cad-labs/ai-cad/tree/main/reference)
  directory ships five distilled CadQuery reference documents,
  which are all the system needs at runtime.

## Reporting problems

Bug reports follow the three-question format in
[CONTRIBUTING.md](https://github.com/ai-cad-labs/.github/blob/main/CONTRIBUTING.md):
your environment, what you asked for, and what happened,
with the run's project directory as the reproduction case.
